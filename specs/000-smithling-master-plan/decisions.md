# Decision log: changes of direction

Every time an earlier decision is **changed** (not just made), it gets an entry here: what we decided before,
what we decided instead, why, and which documents were updated. Current rules live in the
[roadmap](roadmap.md)'s Decisions list; this file keeps the history of how they got there.

Newest first by ID. IDs are stable; link to them as `decisions.md#d-012`. The Date column is when the change was decided;
D-030–D-033 were logged on 2026-11-08 for changes decided earlier that had no entry.
The project was named **tracedb** until D-037; older entries keep that name (crates `tracedb-*` are now `smithling-*`).
Paths in entries before D-034 that say `tracedb` (`lib.rs`, `routes/…`, `langsmith_map.rs`) are now in `crates/server/src`;
seed, scenario, CLI query, demo and bench are in `crates/tools/src`; `main.rs` stays in `crates/smithling`.

## How to add an entry
1. Add a row at the top with the next ID.
2. Update the roadmap's Decisions list to the new rule (it shows what holds now).
3. Fix the affected docs in the same commit, and list them in "Updated".
